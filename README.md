## ✨ Features

- **Editorial Dark Aesthetic**: Bespoke dark color scheme crafted with OKLCH design tokens, hairline grid accents, and subtle typography hierarchy.
- **Interactive Hero**: Kinetic typography reveals, magnetic cursor interactions, dynamic tilt portrait, and real-time marquee ticker.
- **Selected Works**: Interactive showcases for full-stack, AI, and systems engineering projects with live demos and source code links:
  - **PathPilot** — Adaptive LLM roadmap & milestone generator.
  - **MessageMind** — AI-powered message triage & routing workspace.
  - **Triplytics** — Flight & train fare prediction engine (480K+ records).
  - **TaskPro** — Role-based task management & workflow system.
- **Dynamic Skills & Knowledge Graph**: Skill matrix with interconnected relationship graph (Languages, Web, ML, and Systems).
- **Experience Timeline**: Career history with interactive cards and timeline progress visualization.
- **Proof & Credentials**: Recognitions including Amazon ML Summer School (Top 5%), GDG CodeSprint, SparkLab, and verified industry certifications.
- **Embedded Resume Viewer**: Seamless modal for previewing and downloading the latest resume without leaving the site.
- **Fully Responsive & Accessible**: Fluid typography clamp scaling, mobile-first layouts, tap-friendly targets, and reduced-motion support.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kopal-vajp/snap-start-portfolio.git
   cd snap-start-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port shown in your terminal) in your browser.

## 🚢 Deployment

This project is configured with a Nitro server preset compatible with modern serverless and static hosting platforms:

- **Vercel**: Import the repository on Vercel; framework preset will be automatically detected.
- **Cloudflare Pages / Workers**: Pre-configured with Cloudflare module output in `.output/server/wrangler.json`.
- **Netlify**: Connect your repository and run `npm run build` with output directory `.output/public`.

Once deployed, simply update the **Live Demo** link at the top of this README with your deployment URL.
