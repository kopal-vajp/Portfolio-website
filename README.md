# Kopal Vajpayee — Portfolio

Personal portfolio showcasing AI-powered applications, data-driven systems, and full-stack engineering. Built with an editorial dark aesthetic, fluid typography, and interactive micro-animations.

🌐 **Live Demo:** [Add your live link here](https://your-portfolio-domain.com)

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TanStack Start, TypeScript
- **Styling:** Tailwind CSS, OKLCH design tokens
- **Motion:** Framer Motion
- **Tooling:** Vite, Nitro

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/kopal-vajp/Portfolio-website.git
cd Portfolio-website

# Install dependencies
npm install

# Start development server
npm run dev
```
